13. (7 points) Examine this recursive method:
public static String formatList(java.util.ArrayList<String> list, int index) {
if (index >= list.size()) {
return ""; // Base case: end of list
}
String currentElement = list.get(index);
if (index == list.size() - 1) {
return currentElement; // Base case: last element, no comma
} else {
// Recursive step
return currentElement + ", " + formatList(list, index + 1);
}
}
